
# 1.Core foundations (week 1–2)
- Big-O (time/space), counting operations, tight bounds. 
- Arrays, strings, hash maps/sets, sorting idioms, prefix/suffix sums. 
- Math basics: modulo arithmetic, GCD/LCM, overflow handling.
# 2. Bread-and-butter patterns (week 2–4)
- Two pointers (pairs, partitions, in-place array ops). 
- Sliding window (longest/shortest subarray meeting a property). 
- Binary search: on index and on the answer/feasible region. 
- Prefix sums & difference arrays (range queries/updates). 
- Intervals: merge, sweep line, greedy by end time. 
- Monotonic stack/queue: next greater element, window max.
# 3. Recursion, backtracking & DP (week 4–6)
- Backtracking (permutations, subsets, combinations, N-Queens). 
- DP patterns:
  - 1D “best up to i” (house robber, climbing stairs). 
  - 2D grid DP (paths, edit distance).
  - Subsequence DP (LCS/LIS family).
  - Knapsack (0/1, unbounded — think dimensions & transitions).
  - State compression (bitmask DP) when n ≤ 20–25.
# 4. Graphs & trees (week 6–8)
- DFS/BFS, topological sort (Kahn + DFS), connected components. 
- Shortest paths (Dijkstra), when negative edges (Bellman-Ford).
- Union-Find (DSU) for connectivity/kruskal.
- Trees: traversals, LCA, BST invariants, diameter, DP on trees.
# 5. Advanced data structures (week 8–10)
- Heaps / PriorityQueue (k-best, streaming).
- Tries (prefix problems, word search).
- Fenwick/Segment tree (range sum/min with updates).
- Ordered maps (TreeMap/TreeSet) for “neighbors/ceil/floor/kth”.
